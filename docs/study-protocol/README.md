# Practitioner study: prepared for future execution

This draft protocol has not been executed and does not authorise participant recruitment.

Research question: How do architects use trust chains to identify conflicts, challenge assumptions and explain residual risks? Recruit varied logistics, architecture and compliance roles after institutional ethics review. Sampling and sample-size rationale must be agreed with the host researchers.

Interview prompts: describe a recent AI-related sharing decision; identify who had authority; explain evidence accepted and rejected; identify a stakeholder excluded from discussion; describe a disagreement that changed the architecture. Avoid leading questions about trust improvements.

Workshop design: participants compare an unstructured baseline case with a traceable case, then discuss transparency/privacy and automation/control conflicts using original cards. Counterbalance order. The DecidArch abstract motivates reflection, but our workshop is not its validated game.

Consent draft: participation is voluntary; withdrawal, recording permission, retention, access and anonymisation must be approved before use. No usable final consent form exists until the institution supplies lawful wording and contact details.

Data management: separate consent from transcripts; pseudonymise organisations; encrypt approved storage; retain only under the agreed policy. Analysis will combine open coding with a documented disagreement review. Maintain an audit trail of code changes and negative cases. No outcomes are claimed.
