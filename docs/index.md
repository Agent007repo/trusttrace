# TrustTrace

Can a team building an LLM-enabled system show, step by step, why a design choice answers a stakeholder's trust concern, and where that evidence stops? TrustTrace combines a typed metamodel and a traced logistics-compliance case with a pre-registered pilot of obligation extraction by small local models.

Start with the [results](results.md), then the [method](method.md) and [limitations](limitations.md). The full report is [`paper/report.pdf`](https://github.com/Agent007repo/trusttrace/blob/main/paper/report.pdf).
