# How this was built

**Who did what.** Samarth set the research brief and constraints and made the go/no-go decisions. He wrote all 17 gold obligations for the B10 pilot himself, drafting them first and then entering them in a labelling page, and he ran the 60 analysed Mistral generations on his own MacBook Pro (M1 Max). He also does the 30-pair blinded matcher audit. AI coding assistants (Anthropic's Claude) proposed the protocol, wrote the metamodel, trace verifier, collector, matcher, analysis scripts, tests and report drafts, and ran the Qwen generations in a cloud container. Samarth's final review of the report wording is the last step before release.

**Order of events.** The pilot protocol and matching rule were committed before any model output existed; a one-line change to the message layout followed one minute before collection and is logged in `DEVIATIONS.md`. The Qwen outputs were generated before labelling and were kept out of the repository and away from the annotator; a checksum record of them was committed before the labels were imported, and `scripts/verify_seal.py` recomputes it. That record shows the outputs were not changed afterwards; that the annotator did not see them is declared, not provable. The analysed Mistral outputs were generated after the labels were locked. The files that reveal the matcher's decision on each audited pair are kept out of the repository until the audit is recorded.

**How numbers get into the text.** Pilot results, trace counts, the case counts and the conflict table in the report are written by scripts from the committed files (`make analyze`). The report's pattern table is a hand summary of `docs/patterns.md`. Changes to the plan are dated in [`DEVIATIONS.md`](https://github.com/Agent007repo/trusttrace/blob/main/DEVIATIONS.md).

These are independent projects. They are not affiliated with, endorsed by, or built using internal material from TU/e, TU Delft, TNO or any consortium named in them. They use public information, public models and original synthetic examples.
