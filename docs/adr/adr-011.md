# ADR-011: Gate raw-document egress by provider approval

Status: accepted for the synthetic reference implementation. This is an architecture decision record (ADR).

## Context and decision drivers

A stronger external model may give better answers, but sending a raw commercial document to it can move data out of the organisation's control.

Requirements: TR-036. Conflict: CONFLICT-07.

## Considered options

Allow all providers; block all external providers; block raw documents to providers not approved for them while allowing redacted payloads.

## Decision outcome

Each provider record states its location class and whether it is approved for raw documents. The gateway refuses raw-document payloads to unapproved providers and allows redacted ones.

## Consequences

Approval is a declared attribute, not verified residency. Redaction quality is now load-bearing. The location classes are coarse.

## Reflection

Assumption: redacted payloads keep enough signal for useful answers. A data scientist would object that this caps quality. Possible bias: equating EU location with sovereignty. Check: approval is a separate flag from location, so an EU provider is not automatically approved.

The reflection subsection is our proposed adaptation, motivated by the Ethics-Aware DecidArch abstract linked in the source register. We have not validated this adaptation with architects.
