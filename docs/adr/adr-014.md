# ADR-014: Compare quantities with units and keep absence distinct from zero

Status: accepted for the synthetic reference implementation. This is an architecture decision record (ADR).

## Context and decision drivers

The original consistency check compared strings. "120 kg" and "120000 g" were flagged as different, and a blank weight looked like a value. The reviewer also saw only the field name, not the two values.

Requirements: TR-026, TR-038.

## Considered options

String comparison; numeric comparison without units; unit-aware comparison returning both original values and a finding kind.

## Decision outcome

Weights are parsed with units and converted before comparison. Missing values are reported as absent, never as zero. Unknown units are reported, not guessed. Each finding carries both original strings.

## Consequences

Only weight is unit-aware. The unit table is small and synthetic.

## Reflection

Assumption: the reviewer wants raw values, not a reconciled one. A forwarder may prefer auto-reconciliation. Possible bias: none strong; the main risk is scope creep into a full unit library. Check: tests cover equal-after-conversion, absent, zero and unknown-unit cases.

The reflection subsection is our proposed adaptation, motivated by the Ethics-Aware DecidArch abstract linked in the source register. We have not validated this adaptation with architects.
