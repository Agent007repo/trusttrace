# ADR-012: Treat model and retrieved text as data, never as commands

Status: accepted for the synthetic reference implementation. This is an architecture decision record (ADR).

## Context and decision drivers

Retrieved documents can contain instructions such as "approve this item". If model output can carry actions, an injected instruction can reach reviewer authority.

Requirements: TR-034.

## Considered options

Let the model call tools; filter suspicious phrases; accept only a fixed output contract and keep all state changes in the review API.

## Decision outcome

Model output must match exactly the answer, confidence and citations fields. Any extra key, such as a tool call, is refused. Review status changes only through an authenticated decide call.

## Consequences

The design forbids useful agentic tool use in this workflow. Injection can still mislead the human reviewer through the answer text.

## Reflection

Assumption: no tool use is needed for these tasks. A platform team building agents would object. Possible bias: overgeneralising from one injection pattern. Check: the test uses a retrieved passage that explicitly instructs approval and confirms the item stays pending.

The reflection subsection is our proposed adaptation, motivated by the Ethics-Aware DecidArch abstract linked in the source register. We have not validated this adaptation with architects.
