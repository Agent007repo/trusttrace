# ADR-001: Use an allowlist for partner payloads

Status: accepted for the foundation only. This is an architecture decision record (ADR).

## Context and decision drivers

Field-by-field sharing makes the data boundary inspectable. Requirements: TR-001, TR-002.

## Considered options

Pass complete documents; blacklist known secrets; typed field allowlist.

## Decision outcome

Typed field allowlist. Unknown roles fail closed.

## Consequences

New fields require an explicit policy change. Semantic identifiers embedded inside allowed values are not redacted.

## Reflection

The shipper wants proof of isolation; the forwarder may prefer fewer schema changes. A fixed field list risks anchoring. Add new-field failure tests before broadening access.

The reflection subsection is our proposed adaptation, motivated by the Ethics-Aware DecidArch abstract linked in the source register. We have not validated this adaptation with architects.
