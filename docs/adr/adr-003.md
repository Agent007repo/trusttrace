# ADR-003: Validate citations against retrieved passage IDs

Status: accepted for the foundation only. This is an architecture decision record (ADR).

## Context and decision drivers

A source-looking string is not evidence that retrieval produced it. Requirements: TR-009, TR-010, TR-011.

## Considered options

Accept any URL; validate passage membership; verify entailment as well.

## Decision outcome

Validate passage membership and abstain without support.

## Consequences

Membership does not prove entailment or authoritative legal status. Corpus entries are original synthetic text.

## Reflection

The auditor needs entailment checks, which this slice lacks. Confirmation bias could make plausible citations seem sufficient. Add adversarial irrelevant-citation evaluation later.

The reflection subsection is our proposed adaptation, motivated by the Ethics-Aware DecidArch abstract linked in the source register. We have not validated this adaptation with architects.
